# ROAB Foundation - Research Of Abnormal Behaviour

## ARG Website - Phase 1: Public Interface

### Overview

The ROAB Foundation website presents itself as a legitimate research organization dedicated to the study of abnormal behavior patterns and anomalous phenomena.

Phase 1 is designed to appear completely normal and professional. The ARG elements are hidden and must be discovered through investigation.

### Canon Information

#### Personnel

Canonical personnel in Phase 1:

- **Ivo Newton** - Senior Researcher, Behavioral Analysis
- **Emily Enferd** - Research Assistant, Data Management
- **Matteo Simmons** - Head of Security, Security & Containment
- **Dr. Sarah Voss** - Research Scientist, Biological Research
- **Dr. Marcus Webb** - Research Coordinator, Phenomenology
- **James Caldwell** - Field Operations Director
- **Dr. Helena Price** - Department Head, Behavioral Analysis
- **David Torres** - Facility Manager, Security & Containment

**Important:** Athena and Fate do NOT appear in the public personnel database.

#### The Professor

"The Professor" is NOT listed in Phase 1 personnel. His existence is revealed only through deeper story elements.

### Phase 1 Navigation

- **ABOUT** - Organization information
- **DEPARTMENTS** - Research divisions
- **RESEARCH** - Active research programs
- **PERSONNEL** - Employee directory (searchable)
- **CONTACT** - Contact information
- **ARCHIVES** - Public and restricted records

### Accessing Phase 2

Phase 2 is triggered by accessing "THE GAP" archive entry, which requires a password.

**Password:** NEWTON

When the correct password is entered, the website grants access to restricted materials and the navigation expands with new options.

### Technical Details

- Pure HTML/CSS/JavaScript
- Typewriter aesthetic with Courier Prime font
- Modal-based document viewing
- Search functionality for personnel
- Responsive design

### File Structure

- `index.html` - Main page structure
- `styles.css` - Typography and styling
- `script.js` - Functionality and ARG logic
